## 如何按教师的节奏练习

1. 先读第 1 节，说明“为什么需要这个框架”，不要急着背注解。
2. 跟着第 2 节依次完成环境、数据库、工程、实体、Mapper 和测试。每做完一段，都按“验收点”检查结果。**先运行查询，再做新增、修改和删除**，这样更容易定位问题。
3. 第 3 节先观察默认映射，再做映射不一致的小实验；不要一开始就给每个字段添加注解。
4. 第 4 节先确认默认配置能工作，再添加自定义 XML。最后完成文末的综合检查。

## 自测清单

- 能口述 `UserMapper extends BaseMapper<User>` 后为什么可以调用 `selectById`。
- 能指出 `User` 中的 `createTime` 对应数据库的 `create_time`，以及 `id` 的默认识别规则。
- 能在 `user` 表让新增的 `Lucy` 被查到、把余额改为 `20000`，最后只删除这条练习数据。
- 能说明第 3 节切换到 `tb_user` 时为什么需要 `@TableName("tb_user")`。
- 能解释 `@TableName`、`@TableId`、`@TableField` 分别解决什么问题。
- 能让 `UserMapper.xml` 中的 `queryById` 正常执行，并说出 `namespace`、`id`、`resultType` 各自的作用。
